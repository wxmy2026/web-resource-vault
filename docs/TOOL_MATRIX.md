# 工具费用与设备适配

核对日期：2026-08-25。“免费使用”和“开源”不是一回事：开源描述代码许可，免费描述当前是否必须付费。

| 工具 | 核心软件 | 可能收费的部分 | 当前建议 |
|---|---|---|---|
| Obsidian | 免费使用，但不是开源软件 | 官方 Sync：年付时 US$4/月、月付 US$5/月；Publish：年付 US$8/月、月付 US$10/月 | 第一批安装；先用本地 vault |
| AnythingLLM Desktop | 桌面版绝大多数功能免费；自托管版本开源 | Pro、Cloud、第三方模型 API 或云算力 | 第二批启用；先积累干净资料 |
| Anki Desktop / AnkiWeb | 免费、开源 | 官方 iPhone/iPad 版 AnkiMobile 一次性付费，价格以 App Store 当日显示为准 | Mac 先免费用，iPad 先试 AnkiWeb |
| Krita | 免费、开源 | 商店版或捐赠为可选支持 | 第一批安装，作为 Mac 绘画工具 |
| Subtitle Edit 5 | 免费、开源（BSD） | 无必需订阅 | 处理自己拥有或合法取得的视频/字幕时再装 |
| ComfyUI Desktop | 本地引擎免费、开源 | Comfy Cloud、云 GPU、部分闭源模型/API | 第二阶段；Apple Silicon 更合适 |
| Stable Diffusion 模型 | 不是一个单独 App；部分模型可下载 | Stability AI 核心模型的 Community License 对年收入低于 US$1M 的个人/组织免费；其他模型许可各异 | 通过 ComfyUI 管理，不单独堆环境 |
| Open WebUI | 自托管可免费使用；现行许可含品牌限制 | 企业支持、托管、模型 API 和服务器 | 暂缓，避免与 AnythingLLM 重复 |
| FreshRSS | 免费、开源、自托管 | 服务器和域名可能收费 | 私人新闻系统第二阶段 |
| Syncthing | 核心免费、开源 | 某些第三方 iOS 客户端可能收费 | Mac 间同步可用；iPad 体验并非完全等同原生 iCloud |
| Web Resource Vault | 免费、开源（MIT） | 仅在主动连接付费云服务时产生第三方费用 | 当前使用 |

## 结论

当前核心工具没有必须订阅的项目。先用 Mac 端免费组合；需要跨设备同步、云模型或云 GPU 时再决定是否付费。流媒体 App 的 DRM、登录和地区限制不属于资源下载器的能力范围，本项目不会尝试绕过。
