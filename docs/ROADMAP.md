# Personal AI Workbench 路线图

## Phase 1：可靠收集（当前）

- 公开 URL 下载与网页资源发现
- 流式写入、体积限制、重试和伪文件检测
- SHA-256 去重、来源与抓取时间记录
- `robots.txt` 默认合规
- `manifest.json` 与 `index.jsonl`
- Mac 首批软件自动安装入口

## Phase 2：知识化

- PDF、EPUB、DOCX、网页和字幕正文抽取
- Obsidian Markdown 卡片与来源反向链接
- AnythingLLM 增量导入适配器
- IELTS 标签：技能、题型、难度、来源、授权状态
- 从合法内容生成 Anki CSV/APKG

## Phase 3：主动发现

- 允许列表中的官方站点定时发现
- 速率限制、更新检测与失败恢复
- FreshRSS / RSS 连接
- 每日“事实 → 背景 → 多方观点 → 趋势”简报

## Phase 4：创作工作室

- 创作参考图的来源、授权、标签和相似图去重
- ComfyUI 工作流版本管理
- 角色一致性素材包与项目目录

## 边界

- 不绕过付费墙、登录、DRM 或访问控制
- 不抓取版权不明的整套课程、教材或影视内容
- 不把私人原始资料提交到公开 GitHub 仓库
